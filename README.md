## 🤔 켈리 공식이 뭔가요?

투자나 베팅을 할 때 가장 어려운 질문은 **"한 번에 얼마를 걸어야 하나?"** 입니다.

- 너무 **조금** 걸면 → 이겨도 자산이 굼뜨게 불어납니다.
- 너무 **많이** 걸면 → 한 번의 연패로 크게 무너집니다.

**켈리 공식(Kelly Criterion)** 은 "이길 확률"과 "이길 때 벌고 질 때 잃는 정도"를 계산해서, 그 사이의 **수학적으로 가장 이상적인 투자 비중**을 알려줍니다. 1956년 벨 연구소의 존 켈리가 만들었고, 지금도 프로 투자자·트레이더들이 자금 관리(포지션 사이징)에 사용합니다.

## 📝 사용법 — 3가지만 입력하세요

| 질문 | 무엇을 넣나요 | 예시 |
|---|---|---|
| **1. 100번 중 몇 번 이기나요?** | 이 전략의 승률 (과거 경험·백테스트 기준) | `55번` (= 승률 55%) |
| **2. 몇 % 벌고 몇 % 잃나요?** | 이길 때 평균 수익률 / 질 때 평균 손실률 | `+12%` / `−10%` |
| **3. 투자에 쓸 수 있는 돈** | 지금 가진 투자 원금 | `1,000만원` |

그리고 **얼마나 공격적으로 할지** 선택하면 끝:

- **공격적 (풀 켈리)** — 이론상 최댓값. 추정이 조금만 빗나가도 크게 흔들려 위험합니다.
- **안정적 (하프 켈리)** ⭐ **추천** — 풀 켈리의 절반. 안정성과 수익성의 균형이 좋아 실전에서 가장 많이 씁니다.
- **보수적 (쿼터 켈리)** — 풀 켈리의 1/4. 아주 안전하게 가고 싶을 때.

👉 결과는 **"88만원 — 가진 돈의 8.8%를 투자하세요"** 처럼 실제 금액과 비율로 바로 보여줍니다.

---

## 💡 예시로 이해하기

> 승률 **55%**, 이길 때 **+12%** / 질 때 **−10%** (손익비 1.2), 원금 **1,000만원**

이 조건을 넣으면:

- **풀 켈리:** 17.5% → 175만원
- **하프 켈리(추천):** 8.75% → 약 88만원

즉, *"한 번의 거래에 1,000만원 중 약 88만원(8.8%)을 넣고, 이 비율을 꾸준히 지키는 것"* 이 장기적으로 가장 유리하다는 뜻입니다.

> ⚠️ 만약 승률·손익률이 나빠서 계산 결과가 0 이하로 나오면, **"투자하지 마세요"** 라고 알려줍니다. 그건 하면 할수록 손해 보는 구조라는 신호예요.

## 🧮 계산 공식

$$f = \frac{p \times b - q}{b}$$

- **f** = 투자할 비중 (0~1)
- **p** = 이길 확률 (예: 승률 55% → 0.55)
- **q** = 질 확률 = 1 − p
- **b** = 손익비 = 이길 때 수익률 ÷ 질 때 손실률

`f`가 0 이하이면 기댓값이 마이너스이므로 투자하지 않습니다(0으로 처리). 실전에서는 안전을 위해 여기에 0.5(하프)나 0.25(쿼터)를 곱해 씁니다.
